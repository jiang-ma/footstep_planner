5.3.2.1 动力学约束详解
1.1 核心动力学模型框架
采用角动量线性倒立摆（ALIP）模型来描述双足机器人的行走动力学。这个模型将机器人简化为一个倒立摆，通过角动量守恒原理来保证动态稳定性。
1.2 连续步态动力学约束
约束(5.12a) - 单脚支撑期动力学：
x_{k+1} = A_d x_k + B_d u_k
- x：状态向量，包含质心位置、速度等
- u：踝关节力矩输入
- A_d：离散化后的状态转移矩阵
- B_d：离散化后的输入矩阵
这个约束描述了在单个摆动周期内，机器人的状态如何受踝关节力矩的影响而连续变化。
约束(5.12b) - 双脚支撑期重置映射：
x_{k+1} = R(x_k, p_k, p_{k+1})
- R：重置映射函数
- p_k, p_{k+1}：新旧支撑脚位置
这个约束描述了在步态切换（双脚支撑期）时，系统状态因支撑点改变而发生的离散跳变。
1.3 初始状态约束
约束(5.12c) - 初始状态锚定：
x_0 = x_{init}
将质心初始状态锚定在机器人当前测得的状态，确保规划与实际状态的无缝衔接。
1.4 力矩幅值约束
约束(5.12d) - 踝关节力矩限制：
||u||₂ ≤ U_{max}
对踝关节力矩的幅值施加二次约束，要求其二范数不超过机器人踝关节电机所能输出的最大值。
5.3.2.2 运动学与环境约束详解
1.1 摆动腿运动学可达性约束
核心问题：摆动脚的位姿受限于机器人自身连杆结构及关节限位所施加的运动学约束。
可达区域近似方法
图5.3(a) 离散原语集：
- 通过对腿部各关节进行采样，生成离散的足部姿态原语集合
- 精确但计算复杂，不适合直接嵌入优化框架
图5.3(b) 凸梯形区域R_reach：
- 将复杂的可达域用一个凸梯形区域来近似
- 边界可以通过线性不等式约束表示
- 保证了优化问题的数学易解性
约束(5.12f) - 可达性约束
p_{i+1} ∈ Rot(θ_i) · R_{reach}
- p_{i+1}：第i+1个落脚位姿
- Rot(θ_i)：依赖航向角θ_i的二维旋转矩阵
- R_reach：梯形可达区域
三角函数线性化方法
问题：旋转矩阵中的三角函数引入非凸性：
Rot(θ_i) = [cos(θ_i)  -sin(θ_i)
            sin(θ_i)   cos(θ_i)]
解决方案：分段线性近似（PWA）
约束(5.12g)、(5.12h)、(5.12j)：
- 将[0, 2π]划分为L个相邻区间[φ_ℓ, φ_ℓ+1]
- 在每个区间上采用端点线性插值
- 使用Big-M法实现逻辑激活
Big-M线性化示例：
φ_ℓ - M(1 - S_ℓ,i) ≤ θ_i ≤ φ_ℓ+1 + M(1 - S_ℓ,i)
s_i - (g_ℓθ_i + h_ℓ) ≤ M(1 - S_ℓ,i)
(g_ℓθ_i + h_ℓ) - s_i ≤ M(1 - S_ℓ,i)
其中M为足够大的常数，S_ℓ,i为指示变量。
1.2 平面多边形环境约束
核心问题：每个落脚点必须位于可通行的凸多边形区域内。
约束条件分解
条件1：共面约束
- 每个可通行区域r附着在三维平面上
- 平面由法向量n_r = [a_r, b_r, c_r]⊤和原点到平面的有向距离d_r定义
- 落脚点p_i必须满足平面方程：n_r⊤p_i + d_r = 0
等价线性不等式表示：
[ n_r⊤ ]     [ -d_r ]
[-n_r⊤ ] p_i ≤ [ d_r ]
条件2：区域内部约束
- 设区域r在参考水平面上的凸多边形顶点集合为V_r = {v_r,1, ..., v_r,n_r}
- 对每条有向边v_r,jv_r,j+1，构造外法向量n_2D_r,j
- 得到约束：n_2D_r,j⊤p_xy_i ≤ n_2D_r,j⊤v_r,j
区域选择逻辑
二元变量H_r,i：
- 引入二元变量表示落脚点是否属于区域r
- 使用"大M法"实现选择逻辑：A_rp_i ≤ b_r + M(1 - H_r,i)
- 确保每个落脚点有且仅有一个归属区域：∑_{r=1}^R H_r,i = 1
