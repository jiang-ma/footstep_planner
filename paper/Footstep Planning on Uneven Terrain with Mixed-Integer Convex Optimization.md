Footstep Planning on Uneven Terrain with Mixed-Integer Convex Optimization
Robin Deits and Russ Tedrake

摘要— 
我们提出了一种新方法，用于规划机器人在带有障碍物的不平坦地形上行走时的落脚点，该方法使用混合整数二次约束二次规划（MIQCQP）。

我们的方法的独特之处在于，它在一个单一的混合整数优化中处理障碍物避让、运动学可达性和落脚点旋转，这些通常需要非凸约束，并且该优化可以高效求解到全局最优解。

可达性通过机器人脚部可达空间的凸内近似来保证。落脚点的旋转通过正弦和余弦的分段线性近似来处理，设计确保该近似永远不会高估机器人的可达性。障碍物避让通过将环境分解为无障碍物配置空间的凸区域，并将每个落脚点分配到一个这样的安全区域来保证。

我们在简单的2D和3D环境中以及人形机器人感知的真实环境中演示了这种技术。我们还讨论了该算法的计算性能，目前在普通笔记本电脑硬件上，它能够在不到一秒钟内规划几步的短序列，或在几十秒到几分钟内规划10-30步的长序列。

我们的实现可在Drake MATLAB工具箱中获取[1]。

I. INTRODUCTION

落脚点规划器的目的是找到行走机器人可以安全跟随以达到目标的一系列落脚点位置。落脚点规划是对接触运动规划的显著简化，其中全身运动学和动力学通常被粗略近似或忽略，以产生一个可处理的问题。因此，落脚点规划的挑战在于在受约束的环境中找到一条通往目标的路径，同时尊重对落脚点位置和落脚点之间位移的约束。这种规划的示例如图1所示。

从广义上讲，落脚点规划存在两大类方法：离散搜索和连续优化。离散搜索方法通常涉及预计算的动作集：要么表示为从一个落脚点到下一个落脚点的可能位移集，要么表示为环境中的可能支撑点集。将动作链接在一起形成可能的落脚点规划树，可以使用现有的离散搜索方法（如A和RRT）进行探索。使用预计算步位移的动作集方法已被Hornung [3]、Michel [4]、Baudouin [5]、Chestnutt [6]、[7]和Kuffner [8]、[9]使用。类似地，Shkolnik等人使用预计算的动态运动集（而非脚位移）和RRT搜索来为四足动物找到运动[10]。固定支撑点集已被Bretl用于攀爬机器人[11]，并被Neuhaus用于LittleDog四足动物[12]。这些方法可以通过在特定动作会使脚与障碍物碰撞时修剪动作树[8]、[9]、[5]，在树的每个叶节点评估的代价函数中包含障碍物避让[6]、[4]，或在检测到碰撞时调整动作集[7]，来轻松处理障碍物避让。然而，它们也往往面临小动作集和大动作集之间的权衡：小动作集减少搜索树的分支因子，而大动作集覆盖更大范围的真实脚位移空间，但更难搜索[5]。此外，将A或其他启发式搜索方法应用于我们的问题很复杂，因为很难为部分落脚点规划定义良好的启发式函数：我们通常无法知道部分规划需要多少额外的脚步才能到达目标，而无需实际搜索这些步骤[6]。

另一方面，连续优化方法直接将落脚点的位姿作为连续决策变量进行操作。这避免了对一小组固定动作的限制，从而允许探索更多可能的落脚点规划，但在连续优化中正确处理旋转和障碍物避让被证明是困难的。落脚点旋转和障碍物避让通常都需要非凸约束来强制执行，因为旋转矩阵集和封闭障碍物外的点集都是非凸的。对于此类非凸问题，我们通常无法找到完整性或全局最优性的保证[13]。我们提出了一种用于落脚点规划的非凸连续优化，被MIT团队在2013年DARPA机器人挑战赛中使用[14]，但这种优化无法保证其解决方案的最优性或找到绕过障碍物的路径。或者，可以简单地忽略落脚点旋转和障碍物避让：Herdt等人固定落脚点方向并不考虑障碍物避让。这使他们能够形成单个二次规划（QP），可以为行走机器人模型选择最优的落脚点放置和控制动作[15]。

我们选择使用混合整数凸规划（具体来说，是混合整数二次约束二次规划）来提供更强大的连续落脚点规划器。这种规划允许我们对落脚点放置进行连续优化，同时使用整数变量来吸收任何非凸约束。我们通过用分段线性函数近似三角函数sin和cos来处理落脚点放置的方向，使用一组整数变量来选择适当的近似。我们还通过枚举一组凸的无障碍物配置空间区域并使用额外的整数变量将落脚点分配到这些区域，来避免障碍物避让中固有的非凸约束。整数约束的存在显著复杂化了我们的公式，但存在多种用于混合整数凸规划的商业和免费工具，所有这些工具都可以提供全局最优解或适当的不可行性证明[16]、[17]、[18]、[19]。因此，我们可以解决整个落脚点规划问题以达到最优，同时确保障碍物避让，据我们所知，这是以前从未完成的任务。我们的算法产生的落脚点规划如图1和图2所示。

这与Richards等人的工作类似，他们构建了一个混合整数线性规划来规划UAV轨迹，同时避开障碍物[20]。他们将每个（凸的，2D）障碍物表示为一组线性约束，每个约束生成一对半空间，一个包含障碍物，一个不包含。他们为每对半空间分配了一个二进制整数变量，并要求对于每个障碍物，车辆的位置必须至少在一个非障碍物半空间中。我们没有为每个障碍物的每个面添加二进制变量，而是预计算了几个凸的无障碍物区域，然后为每个区域分配一个单一的二进制变量，并要求每个落脚点都分配到一个这样的区域，这大大减少了所需的二进制变量数量。我们生成这些凸无障碍物区域的能力依赖于我们最近开发的IRIS，一种用于计算大型无障碍物空间凸区域的算法[2]。

II. TECHNICAL APPROACH

我们的任务是确定N个落脚点的精确x、y、z和θ（偏航角）位置，受限于以下约束：

每个落脚点不与任何障碍物相交
每个落脚点相对于前一个落脚点的位置处于某个凸可达区域内
为实现这一点，我们将避让所有障碍物的非凸问题转化，而是将问题重新表述为为每个落脚点分配到预先计算的无障碍物地形的凸区域中。然后我们添加二次约束以确保每个落脚点可从前一个落脚点到达，使用正弦和余弦的分段线性近似来处理落脚点旋转

A. 将落脚点分配到无障碍物区域
我们的首要任务是将3D环境分解为一组脚可以安全放置的凸区域。IRIS算法首次在[2]中提出，专为这一特定任务设计，可快速在机器人脚的x、y和θ（偏航角）配置空间中生成无障碍物的凸区域。为此，IRIS从单个无障碍物种子点开始，围绕该点构建一个小的椭球体。IRIS主算法在两个凸优化之间交替进行：首先，生成一组超平面，将椭球体与配置空间障碍物集分离。这些超平面定义的无障碍物半空间的交集是一个多面体。其次，求解一个半定规划，以找到该多面体内的最大体积椭球体。这两个步骤可以重复进行，直到椭球体停止增长，结果就是最终的无障碍物多面体[2]。

对于每个无障碍物地形区域，我们在x、y和z方向上拟合一个与局部地形匹配的平面，并添加额外的线性约束，强制该区域中的落脚点位于此平面上。我们将凸区域的总数标记为R，对于每个区域r，我们用矩阵Ar和向量br标识相关的多面体，使得如果落脚点fj被分配到区域r，则满足：
Arfj ≤br
其中
fj ≡ [xj, yj, zj, θj]^T，且r ∈{1,...,R}

为描述落脚点到安全区域的分配，我们构建一个二进制变量矩阵H ∈ {0,1}R×N，使得如果Hr,j = 1，则表示落脚点j被分配到区域r：
Hr,j ⇒ Arfj ≤br （1）
Σ（r=1到R）Hr,j = 1 ∀j = 1,...,N （2）

式（1）中的蕴含运算符可以使用标准的大M公式转换为线性约束[21]，或由混合整数规划求解器（如IBM ILOG CPLEX [18]）直接处理。约束（2）要求每个落脚点恰好分配到一个安全地形区域。

B. 确保可达性
我们选择将落脚点位置的可达集近似为xy平面中圆形区域的交集，并对偏航角和z方向的落脚点位移添加额外的线性约束。两个这样的圆形区域交集定义的可达集如图4所示。对于每个落脚点j，我们要求：

∥[xj+1, yj+1]^T - ([xj, yj]^T + [cosθj, -sinθj; sinθj, cosθj] p1)∥ ≤ d1 （3）
∥[xj+1, yj+1]^T - ([xj, yj]^T + [cosθj, -sinθj; sinθj, cosθj] p2)∥ ≤ d2 （4）

其中p1、p2是圆心，在落脚点j的坐标系中表示，d1、d2是它们的半径。当θj固定时，约束（3）和（4）是凸二次约束，但将θ作为决策变量引入会通过引入θ的三角函数使约束变为非凸。我们将通过为每个落脚点引入两个新变量来处理这个问题：sj和cj，分别近似sinθj和cosθj。因此，约束（3,4）变为：

∥[xj+1, yj+1]^T - ([xj, yj]^T + [cj, -sj; sj, cj] p1)∥ ≤ d1 （5）
∥[xj+1, yj+1]^T - ([xj, yj]^T + [cj, -sj; sj, cj] p2)∥ ≤ d2 （6）

由于p1、p2、d1、d2是常数，这是一个凸二次约束。

然而，我们的工作尚未完成，因为我们现在必须确保sj和cj近似sin和cos，而不引入非凸三角函数约束。我们选择创建sin和cos的简单分段线性近似，并使用一组二进制变量来确定使用近似的哪一部分。我们构建一个二进制矩阵S ∈ {0,1}L×N，其中L是分段线性段的数量，并添加以下形式的约束：

S,j ⇒ { φ ≤ θj ≤ φ+1; sj = gθj + h

g和h的具体选择非常重要：我们必须确保我们的近似永远不会高估脚放置的可达空间。我们可以通过检查对于所有θ值，约束（5,6）的交集是否包含在约束（3,4）的交集中，来经验验证图3所示近似的正确性。不同方向的落脚点可达集如图5所示。

更典型的方法是定义一个具有m个面的凸多面体，固定在一只脚的坐标系中，另一只脚必须放置在其中。这种方法在无旋转的凸优化中已成功应用[15]，但当引入旋转时会产生非凸约束。这样的多面体将涉及以下形式的约束：

Ω [cj, sj; -sj, cj] ([xj+1, yj+1]^T - [xj, yj]^T) ≤ ω （9）

其中Ω ∈ Rm×2是常数矩阵，ω ∈ Rm是常向量。即使在我们对sin和cos的分段线性近似下，（9）也是一个非凸二次约束，因此与我们的混合整数凸公式不兼容。

C. 确定总落脚点数
一般情况下，我们无法预先知道将机器人带到目标位姿必须采取的总落脚点数，因此需要某种方法来高效确定N。我们当然可以对不同的N值重复优化，通过二分查找找到最小可接受的步数，但为了效率起见，我们更希望避免这种需要多次运行优化器的做法。

我们可以尝试通过将N设置得足够大，并简单地对每个落脚点到目标位姿的距离平方添加成本来确定所需的步数，这会将我们的落脚点计划拉向目标。如果落脚点在N步之前到达目标，我们可以裁剪掉计划末尾的任何额外步数。然而，这种方法会让落脚点规划器在每个落脚点都采用最大允许步长，即使在无障碍物的平坦地形上也是如此。在DARPA机器人挑战赛试验前的实验中，我们确定Atlas双足机器人可以实现40厘米的前进步长，但约20厘米的标称步长更安全、更稳定。因此，我们希望在优化中表达对特定标称步长的偏好，同时仍然允许偶尔需要更长的步长来跨越间隙或避开障碍物。我们可以尝试通过对落脚点之间的相对位移添加额外的二次成本来实现这一结果，但这需要非常仔细地调整每个单独步骤的“到目标距离”成本和“相对步长”成本的权重，以确保成本在每个步骤的标称步长上精确平衡。

相反，我们选择了一个更简单的成本函数，对最后一个落脚点到目标的距离采用二次成本，并对每个落脚点到下一个落脚点的位移使用相同的成本权重。为了控制计划中使用的落脚点数，从而控制每步的长度，我们为每个落脚点添加一个单独的二进制变量，标记为tj（代表“裁剪”）。如果tj为真，则要求步骤j固定在同一只脚的初始位置：

tj ⇒ fj = { f1（如果j为奇数）; f2（如果j为偶数）} （10）

注意，f1和f2是机器人两只脚的固定当前位置。

由于每个tj = 1的落脚点都固定在机器人脚的当前位置，实际用于将机器人移动到目标的落脚点数为N − Σ（j=1到N）tj。通过为每个二进制变量tj分配负值成本，我们可以创造减少计划中使用的落脚点数的激励。为了调整标称步长，我们可以简单地调整分配给tj的成本。增加此成本的幅度将均匀延长标称步长，减小幅度将缩短步长。因此，我们只需调整一个值即可设置所需的步长，同时仍然允许超过此长度的步长。优化完成后，我们可以移除计划开始处所有tj为真的落脚点。

D. 完整公式
将所有部分组合在一起，我们得到完整的落脚点规划问题：

minimize（关于f1,...,fj,S,C,H,t1,...,tj）
(fN − g)^T Qg (fN − g) + Σ（j=1到N）qt tj + Σ（j=1到N-1）(fj+1 − fj)^T Qr (fj+1 − fj)

subject to, for j = 1,...,N

安全地形区域：
Hr,j ⇒ Ar fj ≤ br r = 1,...,R

分段线性sinθ：
S,j ⇒ { φ ≤ θj ≤ φ+1; sj = gθj + h} = 1,...,L

分段线性cosθ：
C,j ⇒ { φ ≤ θj ≤ φ+1; cj = gθj + h} = 1,...,L

近似可达性：
∥[xj, yj]^T − ([xj−1, yj−1]^T + [cj, −sj; sj, cj] pi)∥ ≤ di i = 1,2

将额外步骤固定到初始位姿：
tj ⇒ fj = { f1（如果j为奇数）; f2（如果j为偶数）}

Σ（r=1到R）Hr,j = Σ（=1到L）S,j = Σ（=1到L）C,j = 1

Hr,j, S,j, C,j, tj ∈ {0,1}

步骤位置和差异的边界：
fmin ≤ fj ≤ fmax
∆fmin ≤ (fj − fj−1) ≤ ∆fmax

其中g ∈ R4是x,y,z,θ目标位姿，Qg ∈ S4+和Qr ∈ S4+是目标距离和步骤间距离的目标权重，qt ∈ R是裁剪未使用步骤的目标权重，fmin, fmax, ∆fmin, ∆fmax ∈ R4分别是绝对落脚点位置及其差异的边界。我们还将f1和f2固定为机器人脚的初始位姿。

E. 求解问题
我们已经在MATLAB[22]中实现了这种方法，使用商业求解器Gurobi[16]来求解MIQCQP本身。涉及10到20个落脚点和10个凸安全地形区域的典型问题，可以在配备2.9 GHz Intel i7的Lenovo笔记本电脑上在几秒钟到一分钟内解决。仅涉及几步的较小落脚点计划可以在同一硬件上在不到一秒的时间内解决，因此这种方法能够在行走时以实时速率提供短视域落脚点计划，或在静止时提供涉及复杂路径规划的更长落脚点计划。Mosek优化器[17]也能够以相当的计算速度将我们的公式求解到最优。

III. 结果
为了演示MIQCQP落脚点规划算法，我们首先生成了一组随机2D环境。每个环境由10个方形安全地形区域组成，其中9个均匀随机放置在环境边界内，1个直接放置在机器人的起始位置下方，代表机器人当前占据的地形。目标位姿在环境的xy边界内均匀随机放置，期望方向相对于机器人起始方向在±π/2之间。几个这样的环境和生成的落脚点计划如图2所示。这些环境的计算时间在2.9GHz Intel i7上为1到10秒。本文中显示的所有落脚点计划都是收敛到全局最优成本值的0.1%或更小范围内的结果，如Gurobi所报告。

接下来，我们使用Drake（一种规划和控制软件工具箱）[1]手动生成了几个3D示例环境。这些环境和生成的落脚点计划如图1、6、8所示。IRIS算法[2]用于在整个机器人的非常简单的盒子模型的配置空间中生成凸区域（如图7所示），以避免上半身与环境之间的碰撞。这种方法足以生成丰富的行为，例如侧身穿过狭窄间隙，如图8所示。目前，我们只确保每个落脚点允许机器人的无碰撞姿态，但不考虑这些姿态之间转换过程中的碰撞；我们将在第四节讨论解决这一问题的可能方法。

我们还在真实地形上演示了MIQCQP规划器，使用Atlas收集的传感器数据。为了生成这个计划，我们捕获了类似于DRC试验中遇到的煤渣块堆的LIDAR扫描，并使用MIT团队为DRC开发的感知工具构建了场景的高度图[14]。使用Sobel滤波器对地形中坡度超过预定义阈值的区域进行分类[23]，这些陡峭区域被表示为落脚点规划器的障碍物。我们使用IRIS算法[2]生成了七个覆盖机器人前方感兴趣地形的凸安全地形区域。使用这些区域到不同目标位姿的几个落脚点计划如图9所示。在这种环境中，规划时间从5步计划的2秒或更短到20多步计划的60秒不等。

IV. 结论与未来工作
我们已经展示了一种新颖的落脚点规划方法，它用混合整数凸约束替代了非线性、非凸约束。这使我们能够在旋转的线性近似范围内将落脚点规划问题求解到全局最优。我们将避让障碍物的问题转化为将步骤分配到已知凸安全区域的问题，这些区域可以高效构建。我们的MIQCQP落脚点规划器的主要优势在于其能够在困难地形中生成丰富的落脚点序列，同时保证完整性和全局最优性。我们不依赖采样或固定动作集，这些可能会完全错过安全地形的小区域。我们的方法还能优雅地处理高度变化的地形，因为同一物体在适当情况下可以同时被视为障碍物和行走表面，如图6所示。

另一方面，我们完全依赖于足够多的凸无障碍物区域的存在，以确保能找到通过环境的路径。IRIS算法能高效生成这些区域，但目前需要用户输入来种子每个区域的位置。这是一个好坏参半的情况：通过种子这样的区域，人类操作员提供了关于机器人可能行走表面的有价值输入，但这一要求显然牺牲了机器人的自主性。我们目前正在研究完全自动化生成安全地形区域的方法。此外，我们要求每个安全区域代表地形的平面区域：非平面地形区域会在我们的公式中引入非凸约束，因此不被允许。

未来，我们打算提高生成落脚点计划的速度，因为在机器人开始移动前等待长达一分钟在现实世界场景中可能会令人沮丧。我们可能通过对未来相对较远的落脚点放宽可达性标准来实现这一点。例如，我们可能会考虑计划中前10个落脚点的可达性和方向，但只确保接下来的10或20个落脚点可以分配到安全地形区域，而它们之间的距离不会变得太大。这将显著降低MIQCQP的复杂度，代价是可能通过在简化可达性标准下看起来可行但机器人实际无法通过的区域生成计划。

此外，我们有兴趣将这项工作与MIT机器人运动组目前正在进行的动态行走规划研究相结合。我们的同事打算使用MIQCQP来生成落脚点的初始位置和方向，以及它们对安全地形区域的分配，然后运行额外的优化来规划脚上的接触力、质心轨迹和机器人肢体的完整无碰撞运动。MIQCQP产生的凸安全区域分配应该是后续优化的一组有价值的凸约束。
